# 👗 إيليان ستور - Fashion Store Platform

متجر إلكتروني عربي أنيق وحديث لبيع الملابس، مع لوحة تحكم احترافية لصاحب المتجر.

## 🎯 المميزات الرئيسية

✅ واجهة متجر حديثة ومتجاوبة
✅ عرض المنتجات مع الفلترة والبحث
✅ صفحة تفاصيل المنتج متقدمة
✅ سلة التسوق (Shopping Cart)
✅ صفحة إتمام الطلب والدفع
✅ لوحة تحكم لإدارة المبيعات والطلبات
✅ إحصائيات وتقارير بيعية
✅ دعم اللغة العربية RTL
✅ تصميم عصري باستخدام Tailwind CSS
✅ تطبيق مستجيب (Responsive) لجميع الأجهزة

## 🛠️ المتطلبات

- Node.js 18+ 
- npm أو yarn

## 📦 التثبيت والتشغيل

### 1. استنساخ المشروع
```bash
git clone https://github.com/Reallydz47/fashion-store-platform.git
cd fashion-store-platform
```

### 2. تثبيت المكتبات
```bash
npm install
```

### 3. تشغيل المشروع
```bash
npm run dev
```

ثم افتح المتصفح على: `http://localhost:3000`

## 📂 هيكل المشروع

```
fashion-store-platform/
├── app/                          # صفحات التطبيق
│   ├── page.tsx                 # الصفحة الرئيسية
│   ├── products/                # قائمة المنتجات
│   ├── product/[slug]/          # صفحة المنتج
│   ├── checkout/                # صفحة الدفع
│   ├── dashboard/               # لوحة التحكم
│   ├── layout.tsx               # التخطيط الأساسي
│   └── globals.css              # الأنماط العامة
├── components/                   # مكونات React
│   ├── StoreLayout.tsx          # تخطيط المتجر (Header/Footer)
│   ├── ProductCard.tsx          # بطاقة المنتج
│   ├── ProductDetailClient.tsx  # تفاصيل المنتج (Client Component)
│   └── CheckoutPanel.tsx        # لوحة الدفع
├── lib/                          # دوال المساعدة والبيانات
│   ├── data.ts                  # بيانات المنتجات والإحصائيات
│   └── cart.ts                  # إدارة السلة (LocalStorage)
├── public/                       # الملفات الثابتة
├── package.json                 # المكتبات والإعدادات
├── tsconfig.json                # إعدادات TypeScript
├── tailwind.config.js           # إعدادات Tailwind CSS
└── README.md                    # هذا الملف
```

## 🎨 الصفحات الرئيسية

### 🏠 الصفحة الرئيسية `/`
- عرض البانر الترويجي
- فئات المنتجات
- أكثر المنتجات مبيعًا
- مميزات المتجر

### 🛍️ المنتجات `/products`
- قائمة كاملة للمنتجات
- تصفية حسب الفئة
- تقييم المنتجات
- إضافة للسلة

### 📦 تفاصيل المنتج `/product/[slug]`
- صور عالية الجودة
- الأسعار والخصومات
- اختيار المقاسات والألوان
- مميزات المنتج

### 🛒 سلة التسوق `/checkout`
- عرض المنتجات المختارة
- حساب الإجمالي والشحن
- نموذج البيانات الشخصية
- تأكيد الطلب

### 📊 لوحة التحكم `/dashboard`
- إحصائيات المبيعات
- آخر الطلبات
- أعلى المنتجات
- الإيرادات والبيانات
